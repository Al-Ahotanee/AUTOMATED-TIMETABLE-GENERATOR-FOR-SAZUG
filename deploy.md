Sazug Timetable SystemA highly constrained, minimalist, and logic-heavy university timetable generator built for the Department of Mathematical Sciences. Designed to run efficiently on Render's free tier utilizing a Neon PostgreSQL database.Architecture HighlightsFrameworkless: Pure PHP and PDO.Minimalist: Strictly contained within a maximum of 10 core PHP files.Smart Scheduling: Handles multi-hour courses, lecturer constraints, room capacities, and automated layout generation.PrerequisitesA Neon Database account (Free tier is sufficient).A Render account for hosting the PHP application.Deployment Instructions1. Database Setup (Neon)Log into your Neon dashboard and create a new project with PostgreSQL.Once the project is created, locate your Connection String (it will look like postgres://user:password@hostname/dbname?sslmode=require).Connect to your Neon database using their built-in SQL editor or a tool like pgAdmin/DBeaver.Copy the entire contents of database.sql from this project and execute it in your Neon database. This will create all necessary tables and insert the default seed data (including the default admin user).2. Application Deployment (Render)Push this project repository to GitHub, GitLab, or Bitbucket.Log into Render and click New + > Web Service.Connect your repository.Configure the Web Service settings:Environment: PHPBuild Command: composer install (Only if you end up adding dependencies later, otherwise leave blank or type echo "No build required")Start Command: apache2-foreground (Render's default for PHP applications)Environment Variables:Scroll down to the Environment Variables section and add the following:Key: DATABASE_URLValue: Paste your Neon Connection string here.Click Create Web Service.Render will now build and deploy your application.3. Initial LoginOnce the deployment is live, navigate to your Render URL.Username: adminPassword: admin123Note: Immediately update the admin credentials directly in the database or via the application settings once Phase 2 (Authentication) is implemented.
